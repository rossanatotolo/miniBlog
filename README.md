# MiniBlog

Пользовательский сервис для создания постов.

---

### 1 этап. Как запустить приложение локально - backend (Spring Boot + PostgreSQL)
Для запуска приложения на локальном компьютере необходимо:
- собрать проект с помощью Maven (clean+package),
-  в терминале Git Bash ввести команду:
```bash
docker compose up
```
- Docker Compose запустит контейнер с приложением.

### 2 этап. Как запустить приложение локально - frontend  (SvelteKit)
Для запуска сервера на фронте:
- выполнить 1 этап (backend должен быть запущен),
- на сайте скачать и установить файл Node.js (LTS) версии https://nodejs.org/en/download 
-  после установки, в терминале Git Bash ввести команду:
```bash
npm run dev -- --open 
```
- В браузере автоматически откроется "Главная страница" приложения на локалхосте.
