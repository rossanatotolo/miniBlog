# MiniBlog

Пользовательский сервис для создания постов.

---

### Как запустить приложение локально
Для запуска приложения на локальном компьютере необходимо:
- собрать проект с помощью Maven (clean+package),
-  в терминале Git Bash ввести команду:
```bash
docker compose up
```
- Docker Compose запустит контейнер с приложением.
